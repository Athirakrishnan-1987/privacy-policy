Frequently asked questions

  • CodeRabbit is an AI-powered code review tool that automates the code review process, providing context-aware feedback on pull requests within minutes. It integrates with GitHub and GitLab repositories to offer continuous, incremental reviews, significantly reducing the time and effort required for manual code reviews. By leveraging advanced AI capabilities, CodeRabbit enhances code quality and efficiency while ensuring data privacy and security​.

  • CodeRabbit uses machine learning algorithms to analyze your codebase, identify potential issues, and suggest improvements based on best practices and coding standards.

  • CodeRabbit is designed to work with all programming languages, including but not limited to Python, JavaScript, Java, C++, and Ruby. However, the proficiency of our AI models might vary between languages based on their popularity and the public availability of training data.

  • CodeRabbit takes security, privacy, and compliance seriously. We use industry-standard encryption and security practices to ensure the protection of your codebase and data. CodeRabbit is SOC 2 Type II certified and GDPR compliant, ensuring that your data remains confidential and is used solely to fine-tune your reviews. Additionally, CodeRabbit allows users to opt out of data storage, giving you control over your data privacy while still providing essential code reviews.

  • Yes, CodeRabbit offers a free 14-day Team trial with no credit card required. You can sign up via GitHub or GitLab with just two clicks.

  • CodeRabbit offers Free, Essentials, Team, Advanced, and Enterprise plans. Paid accounts are charged based on contributing developers who create pull requests. CodeRabbit is always free for open-source projects. Usage-based reviews, full codebase security scans, and CodeRabbit Agent are billed separately based on usage.

  • CodeRabbit uses advanced machine learning models trained on a vast dataset of code to provide highly accurate and relevant feedback. However, it is designed to complement, not replace, human review.

  • CodeRabbit is regularly updated to incorporate the latest advancements in AI and code analysis, as well as to address user feedback and requests. View our Changelog to see what’s new.

  • CodeRabbit offers comprehensive support, including documentation, tutorials, and access to a dedicated support team to help with any issues or questions.

  • Rate limits vary by plan and product surface. See Plans and pricing for the current PR, IDE, CLI, file, and chat limits, along with trial and fair-use details.

  • Yes, you can switch between different organizations on CodeRabbit. To do so, click on the organization name in the top-right corner of the CodeRabbit UI.

  • CodeRabbit and GitHub Copilot are both AI-powered coding tools. However, CodeRabbit performs the code reviews centrally as part of the CI/CD pipeline, whereas Copilot is an editor tool which helps developers with code completion as they write the code.

  • CodeRabbit prioritizes the confidentiality and security of your proprietary code by implementing strict security measures to prevent unauthorized access. All data remains confidential and is only used to fine-tune your reviews, with an option to opt out of data storage for added privacy.

  • CodeRabbit does not retain your source code after a review completes, except when review caching is enabled to speed up future reviews. Reviews run in isolated, secure environments, and any cached data is encrypted, used only to accelerate reviews, never used for training, and expires automatically.

  • CodeRabbit offers a multi-layered approach with AI code reviews both in the IDE and in your PR/MR. Developers can install the VS Code plugin for quick reviews on every committed and uncommitted change, no subscription needed. Paid plans (Essentials, Team, Advanced, and Enterprise) unlock higher rate limits and full context-aware reviews.

  • CodeRabbit uses the latest foundational LLMs for code reviews along with built-in intelligence that enhances reviews with additional context around code changes. By analyzing your codebase, file dependencies, and learning from your coding style, CodeRabbit is able to provide highly accurate and relevant feedback that catches 95%+ of bugs.

  • With a paid subscription, you get:

    • Higher rate limits for IDE reviews
    • PR reviews in your Git platforms
    • 40+ integrations with linters and SAST tools
    • Context enrichment through Learnings and agentic chat workflows for code changes and documentation
    • Team additionally includes upstream and downstream workflow actions such as issue planning, unit-test generation, merge-conflict resolution, custom instructions, and higher limits

    Advanced adds integrated continuous security monitoring. For a full list of features included in the paid plans, check out our pricing page.

  • Rate limits vary by plan and product surface. See Plans and pricing for the current PR, IDE, CLI, file, and chat limits, along with trial and fair-use details.

  • CodeRabbit offers community-driven support for free users. Please join our Discord server and we will be happy to help you there.

  • CodeRabbit CLI is an AI code review tool that runs directly in your terminal. It provides intelligent code analysis, catches issues early, and integrates seamlessly with AI coding agents like Claude Code, Cursor CLI, and Gemini to ensure your code is production-ready before it ships.

  • CodeRabbit CLI brings code reviews directly into your development workflow in the terminal, allowing you to review code before commits and PRs. While web-based CodeRabbit focuses on reviewing code after a PR is raised, CLI enables pre-commit reviews of both staged and unstaged changes, creating a multi-layered review process.

  • Bug reports and feature requests can be submitted through our support channels. We prioritize feedback from active CLI users to improve the tool continuously.

    • You can reach us in our Discord community for free support.
    • Paid users can directly contact our support by emailing support@coderabbit.ai.

  • No, you will only be charged for the developers who create pull requests. You also have the option to manually assign seats. You can purchase any number of seats and assign them to specific developers.

  • There is no total limit on the number of pull requests or repositories you can review. Each plan does include a per-developer hourly review allowance to manage bursts of activity. These allowances are subject to our Fair Usage Policy. Usage-based reviews can continue eligible reviews after the included allowance is reached.

  • Yes, seats can be reassigned at any time.

  • Sign up for CodeRabbit using GitHub or GitLab, install CodeRabbit on a public repository, and receive free reviews forever for public repositories. No additional setup is required.

  • Essentials is the new name for Pro, and Team is the new name for Pro Plus. Existing subscriptions will automatically display the new plan name. No action is required.

  • No. Essentials retains the current Pro price of $30 per developer per month, or $24 per developer per month when billed annually. Team retains the current Pro Plus price of $60 per developer per month, or $48 per developer per month when billed annually.

  • Essentials includes AI reviews for pull requests and the CLI, one-click fixes, learnings, coding-agent loops, built-in pre-merge checks, and limited Change Stack access. Team includes everything in Essentials, plus Triage, expanded Change Stack capabilities, custom pre-merge checks, finishing touches such as unit-test generation and merge-conflict resolution, issue planning, post-merge actions, and higher limits for connections and multi-repository analysis.

  • Yes. You can change plans from Subscription and Billing. Upgrades take effect immediately, with prorated billing for the remainder of the current billing cycle. Downgrades take effect at the end of the current billing cycle.

  • The free trial starts on the Team plan, giving you access to Team features for 14 days. When the trial ends, you can choose the paid plan that best fits your needs.

  • Usage-based reviews let eligible PR and CLI reviews continue after your plan’s included limit is reached. Admins can choose Automatic, On demand, or Off and set a monthly spending cap. Continued reviews cost $0.25 per reviewed file and are added to the monthly invoice. Enterprise customers can arrange usage-based billing with their account team.

  • Charges for on demand products are separate from your base plan. CodeRabbit Security Scan uses variable pricing based on the scan. CodeRabbit Agent costs $0.40 per agent minute for cloud coding tasks, Slack, and automations. You are billed based on how many minutes your agents run, after applicable trial and free minutes are used. Enabling paid Agent usage gives everyone in your organization access, with a configurable monthly spending cap.

  • Continuous security monitoring and security reviews on pull requests are included with Advanced and Enterprise. Full codebase scans are available separately with usage-based pricing.
